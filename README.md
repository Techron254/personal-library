# Personal Library 📚

A simple web application that allows users to manage their personal book collection. Users can add books to their library, keep track of which books they have read, and organize their collection in one place.

## Features

- **Add Books:** Add books to your personal collection.
- **Track Reading Status:** Mark books as read or unread.
- **View Your Collection:** Display your books in an organized layout.
- **Remove Books:** Remove books from your collection when needed.
- **Responsive Design:** Use the application on different screen sizes.

## Built With

- HTML5
- CSS3
- JavaScript (Vanilla JavaScript)
